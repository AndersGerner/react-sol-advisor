# React Native and Expo reference

Load this reference when the task involves React Native, Expo, navigation, lists,
animations, native APIs, app lifecycle, linking, offline behavior, background work, or
platform-specific UI.

- Actual installed Expo/RN versions and platform constraints.
- Navigation ownership and typed routes/params.
- App lifecycle and subscription cleanup.
- List identity, virtualization, and measured performance.
- Accessibility roles, labels, actions, focus, and font scaling.
- Safe-area, keyboard, orientation, and platform differences.
- Offline/retry behavior and durable state boundaries.
- Native module or config-plugin escalation to red risk.
- Performance changes only after measurement when possible.
