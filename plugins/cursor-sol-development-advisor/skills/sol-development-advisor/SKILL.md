# Sol Development Advisor for Cursor

Read `../sol-development-advisor-core/SKILL.md` before routing. **React Sol Advisor**
is a legacy alias for the same generic product; it does not select a React-only route.

Emit the shared `ADVISOR ROUTE` block with `CLIENT: cursor` before a subagent call.
Choose Composer for bounded routine work, Luna for specialist implementation/review,
and Grok for high-complexity backend, data, worker, integration, or advice work. Select
`production-delivery` and conditional profiles from owned paths and acceptance.

The bundled models use `inherit`. Run the setup command with exact current
Cursor-native IDs from the user's picker/catalog before pinning models. Always report
requested versus observed model evidence separately; frontmatter proves only the
request. A requested `readonly: true` field is not proof of enforced isolation, so
consequential review records before/after state or requires an independently observed
fresh model. Cursor CLI support is not claimed by this adapter; only the desktop or
editor plugin surface is in scope.

Routine workflow is parent architecture -> Composer -> deterministic verification ->
Luna review when warranted -> Composer correction -> parent acceptance. The parent
retains Linear, worktree, publication, review, merge, closeout, and deployment authority.
